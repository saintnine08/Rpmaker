# RP 캐릭터 기록서

다크 판타지 분위기의 정적 캐릭터 소개 웹사이트 초안입니다. `index.html`을 브라우저에서 열면 바로 사용할 수 있습니다.
완성본 HTML 사이트 내보내기는 로컬 서버 없이 직접 열어도 동작하도록 구성되어 있습니다.
외부 파일 없이 한 파일만 옮겨 쓰려면 `rp-character-editor-single.html`을 사용하세요.
배포할 때는 `dist/index.html` 한 파일만 호스팅에 올리면 됩니다.

## 구성

- 상단 탭: 캐릭터 소개, 스킬 설명, 과거사, 캐릭터 시트
- 각 탭별 편집 가능한 본문
- 문단 사이 이미지 삽입, 기존 이미지 교체/삭제/정렬/가로·세로 독립 크기 조절, 붙여넣기, 드래그 앤 드롭 지원
- 사용자 폰트 파일(`ttf`, `otf`, `woff`, `woff2`) 적용 및 기본 폰트 복원
- 상단 설정에서 사이트 분위기 팔레트 변경
- 브라우저 `localStorage` 자동 저장
- JSON 내보내기와 불러오기 지원
- 완성본 HTML 사이트 내보내기와 비밀번호 기반 편집 잠금 지원

## 파일

- `index.html`: 화면 구조
- `rp-character-editor-single.html`: 서버 없이 직접 열 수 있는 단일 파일 편집기
- `dist/index.html`: 배포용 단일 HTML 파일
- `styles.css`: 다크 판타지 스타일
- `script.js`: 탭 전환, 편집, 저장, 이미지 삽입
- `assets/default-portrait.png`: 기본 샘플 초상 이미지
